# Plan Skill

This skill researches an issue and proposes a plan for its fix.

## Parameters

- `issue_number`: The number of the issue to plan for.

## Tasks

1. Research the codebase to understand the issue.
2. Read the issue body and all comments to gather requirements and feedback from previous plans (if any).
3. Plan the necessary changes.
4. Post the plan as an issue comment ending with `#son-of-anton-plan` on a new line.
